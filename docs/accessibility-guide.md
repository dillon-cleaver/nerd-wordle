# NerdWord Accessibility & Keyboard Navigation

NerdWord provides comprehensive keyboard support and accessibility features for desktop users.

## 🔑 **Keyboard Shortcuts**

### **Game Navigation**

- **Letter keys (A-Z)**: Type letters directly into the game
- **Enter**: Submit your current guess
- **Backspace**: Delete the last letter

### **Modal & Menu Controls**

- **Escape**: Close any open modal (hint modal, info modal)
- **Ctrl+H**: Open/close the "How to Play" info modal
- **Ctrl+G**: Focus the game input area (for screen readers)

### **Alternative Shortcuts**

- **Ctrl+H**: Works on both Windows/Linux and Mac (Cmd+H)

## ♿ **Accessibility Features**

### **Screen Reader Support**

- All interactive elements have proper ARIA labels
- Modal dialogs announce themselves correctly
- Keyboard shortcuts include screen reader hints
- Game state changes are announced

### **Focus Management**

- Tab navigation works throughout the interface
- Modal dialogs trap focus appropriately
- Escape key provides consistent "back" navigation
- Visual focus indicators on all interactive elements

### **Visual Accessibility**

- High contrast color scheme
- Large touch targets for all buttons
- Clear visual hierarchy
- Responsive text sizing

## 🎯 **Navigation Flow**

### **Typical Keyboard Workflow:**

1. **Open game**: Use arrow keys or Tab to navigate
2. **Play game**: Type letters directly, use Enter to submit
3. **Need help?**: Press **Ctrl+H** to open instructions
4. **Check collection**: Navigate to "Words" using tab navigation
5. **Close everything**: Press **Escape** to return to game

### **Power User Tips:**

- **Escape** is your universal "go back" key
- All mouse actions have keyboard equivalents
- Screen reader users can navigate with standard screen reader commands

## 🔧 **Accessibility Standards**

NerdWord follows WCAG 2.1 guidelines:

- **Keyboard Accessible**: All functionality available via keyboard
- **Screen Reader Compatible**: Proper semantic markup and ARIA labels
- **Focus Visible**: Clear focus indicators on all interactive elements
- **Consistent Navigation**: Predictable keyboard shortcuts across the app

## 🎮 **Game-Specific Accessibility**

### **Word Entry**

- Type letters directly without clicking
- Visual and audio feedback for each letter
- Clear indication of current position in word
- Error states announced to screen readers

### **Game Results**

- Win/loss states clearly announced
- Letter correctness indicated with color and screen reader text
- Collection progress accessible via keyboard navigation

---

**Need Help?** Press **Ctrl+H** anytime to see the in-game help, or **Escape** to close any modal and return to the main game.
